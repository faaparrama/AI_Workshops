# Before Thursday: install Antigravity (optional)

On Thursday we watch an AI agent work. An agent does more than chat. It reads files, runs commands and builds things. You can drive one on your own laptop, or you can watch a partner's screen. Both count the same.

**If you want to drive, do this before class (10 minutes):**

1. Download **Google Antigravity** for your computer (Mac or Windows) and install it.
2. Sign in with a Google account.
3. Open it once and find the **agent panel**.
4. In the settings, make sure the agent **asks before it runs a command**. On Thursday you approve each step yourself.

That's all. Don't set up a project yet. We do that together.

**If you'd rather not install AI software,** that's fine. You'll be the observer, and the observer's job is the harder one: you catch what the agent does.

**Problems?** If your laptop won't let you install it (a school-managed machine, no admin password), don't fight it. Come as an observer.
